# Ablation Study Datasets

This folder contains a small subset of datasets used for ablation experiments, provided as examples for reproducibility.

Due to size limitations, only selected datasets are included here.
The complete set of genomic datasets used in this study is available from the original source:

👉 https://github.com/Kari-Genomics-Lab/iDeLUCS

Users are encouraged to download the full datasets from the above repository for comprehensive evaluation.
